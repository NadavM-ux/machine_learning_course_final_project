# שלב 1 — בחירת אוכלוסיית מטרה

**אין קוד בשלב זה** — זו החלטת מחקר בלבד, ולכן התיקייה מכילה רק את ההסבר.

## הבחירה
אוכלוסיית המטרה שנבחרה: **איראנים (Iranian POIs)** — משתמשי X המשתייכים לאוכלוסייה האיראנית
(מקומיים במדינה ובתפוצות).

## שלוש משימות הסיווג (0/1/2 בכל העמודות)

| עמודה | 1 | 0 | 2 |
|-------|---|---|---|
| `target_population` | target (איראני) | non-target | unknown |
| `locals_vs_diaspora` | מקומי (חי באיראן) | תפוצות (איראני בחו"ל) | unknown |
| `person_vs_organization` | אדם | ארגון | unknown |

כלל אצבע: **1 = המילה הראשונה בשם העמודה, 0 = השנייה, 2 = לא ידוע.**
`locals_vs_diaspora` רלוונטי רק כאשר `target_population = 1`.

## הנתונים
סופקו מראש תחת `../data/` (אין איסוף עצמאי). קובץ המועמדים הראשי:
`data/Candidates_user_data_MERGED.csv` — 946 משתמשים.
